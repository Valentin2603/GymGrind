# Игровые ассеты

Сюда кладём будущие спрайты и графику игры.

## Структура

```text
sprites/
  player/
  npc/
  machines/
  zones/
  background/
  ui/
```

## Рекомендуемый формат

- Основной формат: `png`
- Стиль: 2D top-down
- Игрок и NPC: примерно `64x64`
- Тренажёры и зоны: от `96x64` до `192x128`
- Фон пола: тайл или большая картинка под зал

Пути к основным спрайтам уже описаны в `gymgrind.assets.SpriteAsset`.
